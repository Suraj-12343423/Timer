# ⏰ Digital Clock Web App

A simple and elegant digital clock built using **HTML, CSS, and JavaScript**.
It displays the current time, date, and AM/PM format in real-time with a clean UI.

---

## 🚀 Features

* 🕒 Real-time clock (updates every second)
* 📅 Displays current date (day, month, year)
* 🌗 12-hour format with AM/PM
* 🎨 Modern and responsive UI design
* ⚡ Lightweight and fast (no libraries used)

---

## 🛠 Tech Stack

* **HTML** – Structure
* **CSS** – Styling and layout
* **JavaScript** – Functionality and time updates

---

## 📂 Project Structure

```
📁 digital-clock
 ├── index.html
 ├── style.css
 └── index.js
```

---

## ⚙️ How It Works

* Uses JavaScript `Date()` object to fetch current time
* Updates every second using `setInterval`
* Formats time into 12-hour format
* Dynamically updates DOM elements (`time`, `date`, `ampm`)

---

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. That’s it — the clock will start automatically
